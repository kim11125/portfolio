About

소개

기획부터 배포까지 혼자 돌릴 수 있는 풀스택 개발자

Spring Boot + Vue.js 3 기반 풀스택 웹 개발을 주력으로, 다양한 도메인에서 10개 이상의 서비스를 기획·설계·배포까지 단독 또는 소규모 팀으로 개발한 경험이 있습니다.

백엔드에서는 Spring Security 기반 JWT/OAuth2 SSO 인증 시스템, MyBatis 동적 쿼리, AWS S3 스토리지 연동, 마이크로서비스 분리 설계 등 실무 기술을 폭넓게 적용해 왔습니다.

프론트엔드에서는 Vue.js 3 Composition API + Vite 환경에서 PrimeVue, Vuetify, Ant Design Vue 등 다양한 UI 라이브러리를 프로젝트 성격에 맞게 선택·적용해 왔으며, 반응형 레이아웃과 실시간 이벤트 처리 경험도 보유하고 있습니다.

최근에는 Claude AI와 협업하여 Python 기반 알고리즘 트레이딩 시스템(7,383줄)을 단독 설계·운영하며, AI를 설계·구현·리뷰 파트너로 활용하는 개발 방식을 확립했습니다.
